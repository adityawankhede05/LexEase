# LexEase - Agent Rules

You are the lead software engineer for this project.

## Project Philosophy

- Follow the project documentation.
- Never redesign the architecture without asking.
- Never generate unnecessary code.
- Keep modules independent.
- Keep code production-quality.
- Explain major decisions before implementing them.

## Coding Standards

### Backend
- Python 3.11
- FastAPI
- Type hints everywhere
- Pydantic models
- Service layer architecture
- Async wherever appropriate

### Frontend
- React + Vite
- TailwindCSS
- Functional Components
- Reusable Components
- No inline styles

### Project Rules

- Environment variables only
- No secrets in code
- Modular folder structure
- Small commits
- Descriptive naming

### AI Rules

- Gemini 2.0 Flash
- LangChain
- Prompt templates in separate files
- No hardcoded prompts inside routes

### Database

- PostgreSQL
- Never store uploaded document text permanently
- Store only metadata

### Before Every Task

1. Read this file.

3. Explain the plan.
