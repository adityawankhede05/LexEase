IMPORTANT NOTE ON EVALUATION METHODOLOGY
------------------------------------------
All sources below were evaluated against our specific need:
  - Real Indian legal agreement clauses (not court judgments)
  - Multiple domains: Rental, Employment, NDA, Property, Loan, Service, Commercial
  - Risk labels (LOW / MEDIUM / HIGH) already present OR manually annotatable
  - Genuinely diverse clause wording, not template repetition

Caveat: Some sources described by multiple search results may not be fully verified
as genuine human-labelled datasets. Where a source was consistently cited but could
not be directly confirmed (no direct URL access available), this is noted explicitly.

==========================================================================================

Name:            Legal Indian Contract Clauses Dataset
URL:             https://www.kaggle.com/datasets/legal-indian-contract-clauses-dataset
                 (exact slug may vary — search Kaggle for "Legal Indian Contract Clauses")
Platform:        Kaggle
File format:     CSV (legal_contract_clauses.csv)
Licence:         Research and educational use (check specific Kaggle licence terms)

Reported contents:
  - Indian legal contract clauses annotated with:
      clause_type (e.g. Termination, Confidentiality, Arbitration)
      risk_level  (Low, Medium, High)
  - Multiple Indian legal domains represented
  - Designed for ML clause classification and risk prediction training

Estimated size:  Not confirmed — multiple search results describe it as "curated"
                 (likely hundreds to low thousands of rows)

Domains covered: Termination, Confidentiality, Arbitration, and other common clause types
                 Domains include commercial, employment, NDA — exact rental/property
                 coverage not confirmed.

Existing risk labels: YES — Low / Medium / High already annotated
Annotation quality:   Heuristic/expert-labelled (not legal-practitioner validated)
Manual re-annotation: Likely not required — labels already present
Indian domain:        YES — explicitly for Indian agreements

Suitability for project:
  HIGH — This is the most directly relevant source.
  If the dataset genuinely contains risk-labelled Indian contract clauses with wording
  diversity, it would directly address the data gap identified in the audit.

Concerns:
  - Some sources note labels are "based on heuristic or expert judgment" — quality
    must be manually verified before use.
  - Clause wording diversity (same clause type, different risk) has not been confirmed.
  - Size is not confirmed — could be too small to be useful alone.

Action required:
  1. Download and inspect the CSV immediately (free Kaggle account required).
  2. Check: does the same clause type appear with multiple risk levels?
  3. Verify domain coverage includes Rental, Employment, NDA, Property.
  4. Check text diversity — if LOW and HIGH examples of the same clause type look
     almost identical, this data has the same problem as our synthetic data.

SOURCE 3 — Nikhil-AI-Labs/legal-contract-classifier-best (Hugging Face)
==========================================================================================

Name:            Legal Contract Clause Classifier (Training Dataset)
URL:             https://huggingface.co/Nikhil-AI-Labs/legal-contract-classifier-best
Platform:        Hugging Face
Note:            This is a MODEL page, not a dataset page.
                 The training data behind the model may be accessible separately.

Reported model details:
  - Ensemble of Legal-BERT-Base + DeBERTa-v3-Base
  - Trained to classify clauses as: Safe/Standard (Low), Unilateral Termination (Medium),
    Non-Compete (Medium-High), Unlimited Liability (High)
  - Reported accuracy: 97.74%

Risk classification categories:
  Low:         Balanced, reasonable standard terms
  Medium:      One-sided termination, restricted scope
  High:        Unlimited liability, excessive penalties, perpetual obligations

Existing risk labels: YES (model output = risk level)
Indian domain:        Uncertain — this may be primarily US/UK corporate contracts
Manual annotation:    Could use this model as an automatic weak labeller on Indian texts

Suitability for project:
  MEDIUM-LOW for direct data use. The model itself is not Indian-domain specific.
  USEFUL as a weak automatic labeller: run this model over Indian contract PDFs to
  generate candidate risk labels that are then manually verified.

Action required:
  1. Check if training dataset is published separately.
  2. If not, use this model as an automatic annotator on Indian legal texts from
     Source 2 (d-riti) to generate candidate risk labels.
